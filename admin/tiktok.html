Agent éditorial TikTok

Prépare et programme tes TikTok

Décris un chantier ou une idée. L’agent prépare tes légendes, conserve tes brouillons et peut programmer tes propres photos sur TikTok après ta validation.

Ton accord avant chaque publication : l’agent ne programme rien sans clic de validation. Les photos importées reçoivent un lien public pour que Buffer puisse les transmettre à TikTok. Utilise seulement des photos dont tu peux autoriser la diffusion.

Lier TikTok pour programmer des photos

  1. Connecte ton compte TikTok à Buffer.
  2. Crée une clé dans les réglages API de Buffer et ajoute-la dans Netlify sous le nom BUFFER_API_KEY (jamais dans GitHub).
  3. Redéploie le site, puis actualise la connexion ci-dessous.
