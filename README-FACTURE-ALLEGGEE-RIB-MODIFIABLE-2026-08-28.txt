CLEAN-CITÉ — FACTURE ALLÉGÉE + RIB + MODIFICATION
Date : 28/08/2026

Modifications :
- Suppression du bloc bleu « facture finalisée / rectificative / avoir » de la facture imprimée.
- La zone Observations devient « Notes internes » et n'est plus imprimée dans le PDF.
- Mise en page A4 plus compacte pour favoriser une facture sur une seule page.
- Ajout d'un bloc RIB : titulaire, banque, IBAN, BIC.
- Le RIB est mémorisé localement sur l'appareil administrateur et repris sur les PDF et e-mails.
- Une facture enregistrée peut être rouverte puis modifiée depuis l'historique.
- Le numéro de facture reste identique lors d'une modification.
- Chaque ancienne version est archivée côté Netlify Blobs avant mise à jour.
- Un compteur de révision est conservé dans l'administration.
- Si une facture a déjà été envoyée par e-mail, un avertissement apparaît avant modification.

IMPORTANT : renseigner une première fois le RIB dans Admin > Factures > Informations de facture > Coordonnées bancaires à afficher sur les factures.
